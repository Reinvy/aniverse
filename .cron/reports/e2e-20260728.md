## Issues & Recommendations

### 1. Flaky Test: `navigation.spec.ts` — "should have working header navigation"
- **Root cause:** Marketplace link navigates to `/dashboard/marketplace/` which requires authentication. When running tests without a logged-in session, it redirects to `/login`. This causes a mismatch with the expected URL pattern `/\/dashboard\/marketplace/`.
- **Recommendation:** Either:
  - (a) Update the test to handle auth redirect for protected routes, or
  - (b) Add authentication step before clicking protected nav links, or
  - (c) Mark Marketplace as auth-only in the nav test and skip URL assertion for it.
