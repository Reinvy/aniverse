# Bug Fix Report — 2026-07-26 (A13)

## E2E Report Analysis
- **Tests Failed:** 17/17 (100%)
- **Error:** `Cannot navigate to invalid URL` on all specs
- **Root Cause:** Playwright config `baseURL` defaulted to `http://localhost:3000` (no local server). When `URL` env var wasn't set, all relative paths like `/dashboard/challenges` failed to resolve.
- **Evidence:** All 6 test suites affected — challenges, console, dashboard, landing, monetization, navigation

## Fix Applied
**File:** `playwright.config.ts`
- Changed `baseURL` default from `'http://localhost:3000'` → `'https://aniverse-one-khaki.vercel.app'`
- The `process.env.URL` override is preserved for custom targets
- This ensures E2E tests always target production by default
